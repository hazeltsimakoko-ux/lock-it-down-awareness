# Basic Cybersecurity Checklist

Tick each item as you complete it. Review this list every few months.

## Passwords and accounts
- [ ] Every account has a unique password of 12 or more characters
- [ ] I use a password manager or a memorable passphrase
- [ ] Multi-factor authentication (MFA) is on for email, banking and social media
- [ ] I have never shared my password, PIN or OTP with anyone

## Phishing and messages
- [ ] I check the sender's real address before opening a message
- [ ] I hover over links before clicking them
- [ ] I go to official websites myself instead of using links in unexpected messages
- [ ] I treat urgent or threatening messages as suspicious

## Personal information
- [ ] I share my ID number, address and date of birth only when necessary
- [ ] I shred documents that contain personal details
- [ ] I check my bank statements regularly
- [ ] My social media privacy settings are locked down

## Devices and software
- [ ] My operating system and apps are up to date
- [ ] Antivirus is installed and running
- [ ] My devices have a screen lock
- [ ] I avoid public Wi-Fi for banking, or I use a VPN

## If something goes wrong
- [ ] I know who to contact to report an incident
- [ ] I know to change my password straight away if I think I've been hacked
- [ ] I have a copy of the incident report
